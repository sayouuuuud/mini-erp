# قاعدة البيانات

- `bootstrap/001_schema.sql`: مخطط الجداول الأساسي التاريخي، مطلوب قبل الترقيات عند إعداد قاعدة جديدة. لا يمثل إعداد إنتاج مكتملًا بمفرده.
- `migrations/`: ترقيات المصادقة والصلاحيات والكتابة الذرية والمحافظ والورديات والاسترداد والاحتيال، بترتيب أسماء الملفات.
- `tests/`: اختبارات SQL للتكامل؛ منفصلة عن الترقيات ولا تطبق على قاعدة الإنتاج تلقائيًا.

الترقيات التاريخية صممت لقاعدة موجودة وقد تتطلب بيانات أو صلاحيات أو مكونات Supabase محددة. راجعها على قاعدة اختبار أولًا، ثم طبق فقط الترقيات غير المنفذة بالترتيب. إعداد قاعدة جديدة يشمل أيضًا تجهيز هوية مسؤول مصرح بها؛ قوائم البيانات الأولية العامة لا تنشئ حسابات دخول.

ملف المخطط الأساسي يعطل RLS في مرحلته التاريخية الأولى. يجب إتمام ترقيات المصادقة وRLS قبل توصيل مستخدمين إلى قاعدة جديدة. أزيل سكربت منح الصلاحيات العامة القديم لأنه استبدل بترقيات الصلاحيات الحالية.

لم تعد ملفات إصلاح معاملات إنتاج بعينها ولقطات الصلاحيات المؤقتة جزءًا من شجرة المشروع الحالية. سجل Git يحتفظ بنسخها السابقة؛ ليست خطوات إعداد أو صيانة دورية.
